# Police du jeu

Depose ici un fichier **`game.ttf`** et tout le lobby l'utilisera automatiquement
(titres, boutons, compteurs). Aucun code a modifier : `Painter.font()` detecte le
fichier au demarrage et retombe sur la police par defaut de Godot s'il est absent.

Polices gratuites qui donnent le rendu "Supercell" (Brawl Stars / Stumble Guys) :

| Police         | Ou la trouver                          | Rendu                    |
| -------------- | -------------------------------------- | ------------------------ |
| Lilita One     | fonts.google.com/specimen/Lilita+One    | tres proche de Brawl Stars |
| Luckiest Guy   | fonts.google.com/specimen/Luckiest+Guy  | plus cartoon / arrondi   |
| Bungee         | fonts.google.com/specimen/Bungee        | plus massif              |

Telecharge le `.ttf`, renomme-le `game.ttf`, pose-le dans ce dossier, relance le jeu.
